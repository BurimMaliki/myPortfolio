02 · Bildungsweg

Informatikmittelschule (IMS)

Die Informatikmittelschule (IMS) ist ein vierjähriger Bildungsgang in der Schweiz: drei Jahre Schule, ein Jahr Praktikum — mit Abschluss eidgenössisches Fähigkeitszeugnis (EFZ) als Applikationsentwickler:in plus Berufsmaturität.

Der Unterricht verbindet Allgemeinbildung mit Informatik — von Programmierung und Webentwicklung über Datenbanken und Netzwerke bis zu Projektmanagement. Welche Module zum EFZ führen, zeigt der offizielle Modulbaukasten. Angeboten wird die IMS unter anderem an der Kanti am Brühl (KSB) in St. Gallen.

04 · Arbeit

Projekte

Drei Projekte, drei Ansätze: eine Meal-Planning-App, ein spielbares Strategie-Spiel und das Konzept für eine Lernplattform.

App · Frontend

FoodSync

FoodSync ist eine Meal-Planning-App auf React-Basis: Demo-Profile mit Kalorien- und Makro-Zielen, dazu persönliche Empfehlungen, die Allergien und Ernährungsweisen wie vegetarisch berücksichtigen und zum verbleibenden Tagesbudget sortiert sind. Mahlzeiten lassen sich von Montag bis Sonntag in einen Wochenplan legen — inklusive Tages- und Wochen-Tracking der Kalorien, anpassbarem Kalorienziel und Berechnung nach Harris-Benedict. Aus allen geplanten Mahlzeiten entsteht automatisch eine kategorisierte Einkaufsliste mit zusammengeführten Mengen zum Ausdrucken.

  • React & JavaScript
  • Tailwind CSS
  • Wochenplan
  • Einkaufsliste
  • Harris-Benedict
Tech-Stack
React · JavaScript · Tailwind CSS
Status

RoboFight

Zwei Spieler bauen Roboter aus drei Werten — Stärke, Tempo und Robustheit — und lassen sie gegeneinander antreten. Wie bei Schere, Stein, Papier kontert jeder Wert einen anderen; eine spezielle Kampfformel entscheidet den Kampf.
